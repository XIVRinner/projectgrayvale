## Keyword Entries

### dot-conversion
- Canonical definition: Applies qualifying DoT states to build a delayed conversion window, then consumes/leverages that DoT-state for amplified finisher impact.
- Allowed interpretation boundaries: Multi-DoT setup whose primary payoff is finisher conversion; finisher scaling by qualifying DoT count, potency, duration-state, or other explicitly DoT-derived state.
- Forbidden interpretation boundaries: Treating the archetype as pure sustained DoT DPS; granting conversion from non-DoT states; uncontrolled conversion from arbitrary external sources unless explicitly defined by archetype rules.
- Interaction notes: Distinct from DoT-applier identity; DoT-applier pressure is tick-damage-first, while dot-conversion pressure is setup-then-cashout timing.
